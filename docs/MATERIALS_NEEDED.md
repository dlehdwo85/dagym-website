# 다짐에서 확인 · 제공해야 하는 자료

사이트에는 **확인된 정보만** 공개합니다. 아래 항목이 확인되기 전까지 해당 영역은 방문자에게 보이지 않습니다.

## 1. 회사 기본정보 — `data/config.ts` › `company`

| 항목 | 현재 | 참고 |
| --- | --- | --- |
| 대표자 | 숨김 | 커뮤니티 운영 제안서 표지에 대표자 성명 기재. 공개 여부 확인 후 입력 |
| 대표번호 | 숨김 | 제안서 표지에 휴대폰 번호 기재. **홈페이지에 공개할 대표번호**인지 확인 필요 |
| 이메일 | 숨김 | 제안서 표지에 이메일 기재. 공개용 주소인지 확인 후 입력 |
| 사업자등록번호 · 주소 · 설립일 | 숨김 | 사업자등록증 기준으로 입력 |
| 상담 가능 시간 | 숨김 | 예) 평일 09:00–18:00 |

## 2. 운영 현장 — `data/projects.ts`

- 공개 가능한 운영 현장: 단지명, 지역, 세대수, 운영 시설, 운영 기간, HILINK 적용 여부, 현장 사진
- **계약사 · 입주자대표회의의 공개 동의**를 받은 현장만 `verified: true` 로 입력합니다.
- 제안서에 "주요 이력"으로 기재된 운영 현장이 있으나, 공개 동의와 운영 여부를 확인하지 못해 싣지 않았습니다.
- 확인된 현장이 1곳 이상 입력되면 홈 · 메뉴 · 운영사례 페이지가 자동으로 노출됩니다.

## 3. 사진 — `docs/PHOTOS.md`

첫 화면 사진 1장, 사업영역 사진 2장, 현장 업무 사진 1장이 최우선입니다.

## 4. HILINK 실제 화면

입주민 앱과 관리자 화면 캡처 (개인정보 가림 처리). 확보되면 HILINK 페이지에 제품 화면이 표시됩니다.

## 5. 수치 · 성과 (공개하지 않음)

제안서에는 매출 증가율, 재계약률, 만족도 상승률 같은 수치가 있으나 산출 근거를 확인하지 못해 **사이트에 쓰지 않았습니다.**
근거 자료(기간, 대상 현장, 산출 방식)가 확인되면 회사소개 또는 사업영역에 출처와 함께 추가할 수 있습니다.

## 6. 그 밖의 자료

- 공식 로고 파일 (SVG) — 현재 텍스트 로고 사용 중
- 공식 브랜드 컬러 — 현재 딥 네이비 `#1f3a5c`
- 연혁 · 인증 · 협력사 (공개 가능한 것만)
- 개인정보처리방침 최종본 (법무 검토)
- 문의 접수 담당자 메일 주소 (`docs/CONTACT_SETUP.md`)
